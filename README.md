# Agent Lab — русская автономная версия

Учебная игра по построению ИИ-агентных систем. Она работает полностью в
браузере, не обращается к LLM/API и не требует сборки.

## Запуск

Откройте `index.html` двойным щелчком. Для локальной разработки можно также
запустить любой статический HTTP-сервер в этой папке.

В первой версии полностью реализована миссия «Марсианская станция». Остальные
миссии показаны в меню как будущие конфигурационные сценарии.

## Управление

- Добавьте 3–5 агентов из библиотеки.
- Выберите агента в центре, затем назначьте ему RAG, навыки и инструменты.
- Нажмите шестерёнку агента, чтобы задать цель и маршруты.
- Проверьте архитектуру и запустите симуляцию.
- В режиме преподавателя доступны события, подсказки и эталонная команда.
- `F` включает и выключает полноэкранный режим.

Прогресс автоматически сохраняется в `localStorage` текущего браузера.
